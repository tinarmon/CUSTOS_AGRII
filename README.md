## 🌟 โครงสร้างระบบและฟังก์ชันระดับมืออาชีพ (Professional Architecture)

เว็บแอปพลิเคชันนี้ถูกออกแบบขึ้นมาใหม่เพื่อลบภาพจำแบบ "เว็บหน้าเดียวที่ยัดทุกอย่าง" สู่ **Smart AgTech SaaS Platform เต็มรูปแบบ** ประกอบด้วยส่วนประกอบสำคัญ:

### 1. ระบบนำทางและข้อมูลแปลง (Top Navigation & Farm Selector)
* **Farm Selector:** สามารถสลับดูข้อมูลระหว่าง 3 แปลงต้นแบบได้ทันที (เช่น แปลงสวนตาเพิ่ม ฉะเชิงเทรา รหัส พช. `CDD-CS-207`, ศูนย์เรียนรู้กสิกรรมธรรมชาติ อ.แปลงยาว, แปลง Young Smart Farmer โคราช)
* **Official Data Badge:** แบนเนอร์แสดงการเชื่อมโยงฐานข้อมูลแปลงโคกหนองนา **41,798 แห่ง ทั่วประเทศ ของกรมการพัฒนาชุมชน กระทรวงมหาดไทย**
* **Notification Center:** เมนูแจ้งเตือน Dropdown พร้อมตัวนับแจ้งเตือนแบบเรียลไทม์

### 2. ระบบสลับบทบาทและจำลองผู้ใช้งาน (User Persona & Auth Modal)
คลิกที่โปรไฟล์มุมขวาบนเพื่อเปิดหน้าต่างสลับบทบาทสาธิตได้ 3 กลุ่มเป้าหมาย:
* **นายสมคิด ใจดี:** เจ้าของแปลงโคกหนองนา (ปราชญ์ชาวบ้าน)
* **นายพิชัย นิลแก้ว:** พัฒนากรชำนาญการ (กรมการพัฒนาชุมชน กระทรวงมหาดไทย)
* **น.ส. กานต์ดาว ชัยชนะ:** เกษตรกรรุ่นใหม่ (Young Smart Farmer - YSF)
* พร้อมหน้าจำลอง **เข้าสู่ระบบ (Login)** และ **ลงทะเบียนแปลงใหม่ (Register Farm)** สำหรับโชว์ขั้นตอน User Onboarding

### 3. แยกแท็บการจัดการตามหลัก "โคก - หนอง - นา" (Multi-Tab Views)
* 📊 **ภาพรวมแปลง (Overview Dashboard):** 4 การ์ด KPI สำคัญ, แผนผังวงจรเกื้อกูล (Circular Smart Harmony), กราฟสถิติ 7 วัน (Chart.js), และตัวจำลองการแจ้งเตือนผ่าน LINE Phone
* 🏔️ **โซนโคก (Khok Zone):** ดัชนีความชื้นดิน (Capacitive Matrix), สวัสดิภาพเล้าไก่ไข่/คอกสัตว์ (ระดับเสียงเดซิเบล), สภาพอากาศจุลภาค (VPD)
* 💧 **โซนหนอง & คลองไส้ไก่ (Nong Zone):** ภาพจำลองหน้าตัดระดับน้ำในสระ (Reservoir Depth Gauge) ความลึก 3 เมตร, อัตราการระเหย, และการสั่งเปิดปั๊มน้ำโซลาร์เซลล์
* 🌾 **โซนนา (Na Zone):** ท่อตรวจวัดระดับน้ำแกล้งข้าว (AWD Tube Visualizer) แสดงระดับน้ำใต้ดิน -15 ซม. พร้อมคำแนะนำการขังน้ำ 5 ซม.
* 📹 **ระบบเฝ้าระวังกลางคืน (Night Guardian CCTV):** หน้าจอสตรีมมิ่งกล้องอินฟราเรด 2 ตัว (เล้าไก่ไข่ และ สระน้ำ/คลองไส้ไก่)
* 📑 **บันทึกข้อมูล (Telemetry Logs):** ตารางข้อมูล TimescaleDB พร้อมระบบค้นหา (Search Filter) และปุ่มดาวน์โหลด CSV
* ⚙️ **การตั้งค่า & เชื่อมต่อ LINE (Settings):** สถานะ LINE Messaging Webhook (200 OK) และแถบสไลเดอร์ปรับค่า Thresholds

## 🚀 วิธีเปิดใช้งานและทดสอบ (How to Run)

1. **เปิดดูในเครื่องคอมพิวเตอร์ทันที (Local Run):**
   * ดับเบิลคลิกไฟล์ [index.html](file:///c:/Pitching/Developer_side/Website%20mockup/index.html) ในเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox)
2. **นำขึ้น GitHub Pages:**
   * Push โฟลเดอร์ `Website mockup` หรือไฟล์ `index.html` ไปยัง GitHub Repository ของคุณ
   * เปิดแท็บ **Settings** ➔ **Pages** ➔ เลือก Source: `Deploy from branch` ➔ เลือกโฟลเดอร์ที่มี `index.html`
   * จะได้ URL สาธารณะ เช่น `https://<username>.github.io/<repo>/`

## 🎙️ ตัวอย่างบทสาธิตตอน Pitching (Pitching Flow)

1. **เริ่มต้น:** แสดงหน้า **Overview Dashboard** อธิบาย 4 KPI และแบนเนอร์ฐานข้อมูล พช. 41,798 แห่ง
2. **สลับบทบาท:** คลิกโปรไฟล์มุมบนขวา แสดงหน้าต่าง Login/Demo Persona ว่ารองรับทั้งชาวบ้านและเจ้าหน้าที่ พช.
3. **เจาะลึก 3 โซน:** คลิกแท็บ **โซนโคก**, **โซนหนอง**, และ **โซนนา** แสดงให้เห็นว่าระบบเข้าใจภูมิปัญญาโคกหนองนาอย่างแท้จริง (เช่น ท่อแกล้งข้าว AWD และการคำนวณน้ำระเหย)
4. **โชว์หมัดเด็ด:** คลิกแท็บ **กล้องกลางคืน** และทดสอบกดปุ่ม **"🚨 สัตว์บุกเล้าไก่"** ในหน้า Overview เพื่อแสดงการ์ดเด้งแจ้งเตือนเข้าสู่ LINE ทันที
